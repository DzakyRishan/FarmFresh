# FarmFresh Market - E-Commerce Sayur Segar dari Petani

## 📋 Deskripsi Proyek
FarmFresh Market adalah platform e-commerce yang menghubungkan petani lokal langsung dengan konsumen. Aplikasi ini memungkinkan petani untuk menjual produk pertanian mereka dan konsumen untuk membeli sayuran segar langsung dari sumbernya.

## 🚀 Fitur Utama

### Untuk Konsumen:
- ✅ Registrasi dan login
- ✅ Pencarian produk dengan filter
- ✅ Keranjang belanja
- ✅ Checkout dan pembayaran
- ✅ Riwayat pesanan
- ✅ Update profil

### Untuk Petani:
- ✅ Dashboard manajemen produk
- ✅ CRUD produk
- ✅ Kelola stok
- ✅ Lihat pesanan
- ✅ Update status pesanan

## 🛠️ Teknologi yang Digunakan
- **Backend:** Java Spring Boot
- **Frontend:** Thymeleaf, HTML, CSS, JavaScript
- **Database:** MySQL
- **Build Tool:** Maven
- **ORM:** Spring Data JPA (Hibernate)
